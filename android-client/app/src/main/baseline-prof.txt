# install time instead of being interpreted then JIT-ed on first run. This is the
# single largest cold-start win available to a Compose app (typically 20-30% off
# time-to-first-frame), and it costs nothing at runtime.
#

#
# These wildcard rules cover the whole auth path, which is by definition everything
# that runs before the user sees content. Compose's own profiles ship inside the
# AndroidX artifacts and are merged with this file by AGP.
